# External specifications

Specifications Biblio relies on. None is collected here yet: each is linked, and a local copy
goes in this directory when one is saved.

| Title | Source | Why it applies |
|---|---|---|

| BiblioCommons libraries directory | <https://www.bibliocommons.com/libraries-we-work-with> | Library suggestions and partner logos |
| Code 128 | ISO/IEC 15417; see [Wikipedia](https://en.wikipedia.org/wiki/Code_128) | The alternative library card barcode |
| Codabar | None freely published; see [Wikipedia](https://en.wikipedia.org/wiki/Codabar) | The library card barcode |

| GNOME Human Interface Guidelines | <https://developer.gnome.org/hig/> | GNOME app design |
| libadwaita | <https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/> | GNOME widgets |
| Secret Service API | <https://specifications.freedesktop.org/secret-service-spec/latest/> | GNOME credential storage |
